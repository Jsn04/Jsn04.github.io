Background

The Problem We Solved

Most language apps are built around repetition: vocabulary flashcards, fill-in-the-blank exercises, recorded audio clips. They teach words in isolation. But real fluency comes from context: understanding what to say when a doctor asks about your symptoms, or when a landlord asks about your rental history. That gap is what LinguaNova was built to close.

The key insight was to simulate environments rather than teach vocabulary. Instead of "here is the word for reservation," the app drops you into a conversation with an AI restaurant server and lets you figure it out. Real-time translation means you can fall back to your native language mid-sentence, and the AI keeps the conversation coherent.

Core Features

How It Works

🎭
Immersive Roleplay

Google Gemini plays a context-specific character: a restaurant server, a bank clerk, a doctor. The model is given a detailed persona and scenario constraints, then maintains a coherent conversation across multiple turns. Temperature is kept low (0.5) so responses stay practical and on-topic rather than creative.

🖼️
Image-Based Vocabulary

WorqHat's image AI generates visual representations of words and phrases in context. Instead of seeing "apple = manzana," you see an image of someone buying apples at a market with the vocabulary labeled. Visual anchors make recall significantly stronger than text-only repetition.

📖
Story Mode

Adaptive narratives that branch based on user choices. Difficulty scales with performance: beginners get shorter sentences and common vocabulary, advanced learners get idiomatic expressions and complex grammar. The story always stays coherent even as the learner makes different choices.

🌍
Real-Time Translation

Google Cloud Translate handles bidirectional translation in every roleplay session. User input in any language is translated to English before being sent to Gemini, and the AI response is translated back to the learner's chosen language. Both the original and translated text are shown so learners can compare.

Technical Detail

How a Roleplay Session Runs

Each scenario module follows the same structure. Gemini is initialized with a domain-specific system prompt that defines the AI character's role, available topics, tone, and example interactions. A persistent chat history object maintains conversation context across turns. The user's input is first translated to English via Google Cloud Translate, sent to Gemini, and the response is translated back to the learner's chosen language before display.

# Simplified session flow from Roleplay/restaurent.py model = setup_gemini() # gemini-1.0-pro, temp=0.5, max_tokens=200 chat = model.start_chat(history=[]) chat.send_message(domain_context) # inject persona + topic constraints while user_continues: user_input = input("You: ") english_input = translate(user_input, 'en') response = chat.send_message(f"Customer: {english_input}") translated_out = translate(response.text, preferred_language) print(translated_out) print(f"(English: {response.text})") # always show both

The dual-display approach (target language + English) is intentional: learners can verify they understood the meaning while still being exposed to the foreign language form. Response length is capped at 200 tokens so the AI stays concise rather than generating long explanations mid-conversation.

Architecture

System Overview

The translation layer wraps every Gemini call, making the roleplay language-agnostic. The user sets their preferred language once at session start, and all subsequent responses arrive in that language with the English version shown alongside for reference.

Engineering Notes

Key Design Decisions

Low temperature (0.5): Language learning apps need predictable, correct responses. A high-temperature Gemini might produce creative but grammatically unusual sentences, which is counterproductive when the user is trying to learn proper usage. temp=0.5 with top_k=20 keeps the model grounded in common, natural phrasing.

Response cleaning: Raw Gemini output sometimes includes role labels ("Server:", "Guide:") or asterisk-marked actions. The clean_response() function strips these with regex before display, so the user only sees the actual dialogue.

Dual display: Showing both the translated response and the English original is deliberate. Learners can check their comprehension while still being immersed in the target language. It also surfaces translation artifacts when the target language is unusual or the sentence structure differs significantly.

Scenario-as-module pattern: Each of the 10 domains is its own Python file with its own system prompt, context, and main function. This made parallel development possible during the hackathon: different team members could work on different scenarios without merge conflicts, and each module is independently testable.
